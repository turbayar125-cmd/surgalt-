# Сургалтын бүртгэлийн систем — тохируулах заавар

Систем 3 үнэгүй үйлчилгээ дээр ажиллана:

| Үйлчилгээ | Юунд | Үнэгүй хязгаар (одоогийн байдлаар) |
|---|---|---|
| **Supabase** | Өгөгдлийн сан, нэвтрэлт, профайл зураг, өдөр бүрийн сануулга | 500 MB сан, 1 GB зураг. 7 хоног огт ашиглаагүй бол түр зогсоно (dashboard-оос нэг товчоор асаана) |
| **Resend** | Имэйл илгээх | Өдөрт 100, сард 3,000 имэйл |
| **GitHub Pages** | `otpclicenses.mn` дээр вэб хуудсыг байршуулах | Хязгааргүй |

Файлууд: `index.html` (апп), `setup.sql` (сан), `CNAME` (домэйн).

---

## 1. Supabase project үүсгэх (5 мин)
1. https://supabase.com → **Start your project** → GitHub эсвэл имэйлээр бүртгүүлнэ.
2. **New project** → нэр: `surgalt`, нууц үг өгнө, Region: **Singapore** (Монголд хамгийн ойр).
3. Project бэлэн болтол 1–2 минут хүлээнэ.

## 2. Өгөгдлийн сан үүсгэх
1. Зүүн цэс → **SQL Editor** → **New query**.
2. `setup.sql` файлыг нээгээд бүх агуулгыг хуулж буулгана → **Run**.
3. "Success" гарвал болсон. 6 алба, 7 сургалтын төрөл автоматаар үүснэ (дараа нь апп дотроос нэрийг нь засна).

## 3. Нэвтрэх эрх тохируулах
1. **Authentication → Sign In / Providers → Email**: **Allow new users to sign up**-ийг **унтраана** (гадны хүн бүртгүүлэхгүй).
2. **Authentication → Users → Add user → Create new user**: хүний нөөцийн ажилтны имэйл, нууц үг. **Auto Confirm User**-ийг чагтална.
3. Хэдэн ч хүнд эрх өгч болно.

## 4. Апп-ыг Supabase-тэй холбох
1. **Project Settings → API** (эсвэл **Data API**) хэсгээс:
   - **Project URL** (жишээ: `https://abcdxyz.supabase.co`)
   - **anon public** key
2. `index.html`-ийг Notepad-аар нээж, доорх мөрүүдийг олж бөглөнө:
   ```js
   const CONFIG = {
     SUPABASE_URL: 'https://abcdxyz.supabase.co',
     SUPABASE_ANON_KEY: 'eyJhbGciOi...'
   };
   ```
   anon key-г нийтэд харуулахад аюулгүй — эрхийг сангийн RLS хамгаална.

## 5. Имэйл илгээх (Resend)
1. https://resend.com → бүртгүүлнэ.
2. **Domains → Add Domain** → `otpclicenses.mn`.
3. Resend хэд хэдэн DNS бичлэг (TXT, MX) өгнө. Тэдгээрийг домэйнийхээ DNS удирдлагад (A бичлэг нэмдэг тэр хуудас) **яг ижилхэн** нэмнэ → Resend дээр **Verify**. Баталгаажих хүртэл хэдэн минутаас хэдэн цаг болно.
4. **API Keys → Create API Key** (Sending access) → `re_...` түлхүүрийг хуулна.
5. Supabase → SQL Editor дээр (өөрийн түлхүүрээр солиод) ажиллуулна:
   ```sql
   select vault.create_secret('re_ТАНЫ_ТҮЛХҮҮР', 'resend_api_key');
   ```
   Түлхүүр шифрлэгдэж хадгалагдах тул вэб хуудсанд харагдахгүй.

## 6. Вэбийг otpclicenses.mn дээр гаргах (GitHub Pages)
1. https://github.com → бүртгүүлнэ → **New repository** → нэр: `surgalt`, **Public** → Create.
2. **Add file → Upload files** → `index.html` болон `CNAME` файлыг чирж оруулна → **Commit**.
3. Repository → **Settings → Pages** → Source: **Deploy from a branch**, Branch: `main` / `(root)` → Save.
4. Custom domain талбарт `otpclicenses.mn` гарсан эсэхийг шалгана.
5. Домэйны DNS удирдлагад (таны зурган дээрх хуудас) **4 A бичлэг**:

   | Хост нэр | IPv4 хаяг |
   |---|---|
   | `@` | 185.199.108.153 |
   | `@` | 185.199.109.153 |
   | `@` | 185.199.110.153 |
   | `@` | 185.199.111.153 |

   Мөн `www` хостод **CNAME** бичлэг: утга нь `ТАНЫ-GITHUB-НЭР.github.io`
6. 10 минут – хэдэн цагийн дараа GitHub → Settings → Pages дээр **Enforce HTTPS**-ийг асаана.

## 7. Эхлүүлэх
1. https://otpclicenses.mn руу орж 3-р алхамд үүсгэсэн эрхээр нэвтэрнэ.
2. **Тохиргоо** → албадын нэр, сургалтын төрөл, хүчинтэй хугацааг (сараар) засна. Хүний нөөцийн имэйл, илгээгчийг бөглөж хадгална.
3. **Тохиргоо → Импорт**: 150 ажилтнаа Excel-ээс "CSV UTF-8" хэлбэрээр хадгалаад оруулна. Дараа нь сургалтуудын CSV-г оруулна.
4. Ажилтан бүрийн профайл дээр дарж зураг оруулна (автоматаар жижигрүүлж хадгална).
5. **Тохиргоо → Одоо илгээх** дарж эхний сануулгыг туршина.

## Сануулга хэрхэн ажилладаг вэ
- Өдөр бүр **09:00** (Улаанбаатар) цагт автоматаар шалгана.
- Анхдагч тохиргоо: дуусахаас **30, 14, 7, 1** хоногийн өмнө болон **дуусах өдөр** — тус бүр нэг удаа.
- Имэйл ажилтанд очиж, хүний нөөцийн имэйлд хуулбар очно. Ажилтан имэйлгүй бол зөвхөн хүний нөөцөд очно.
- Сургалтыг **Сунгах** дарж шинэчилбэл хуучин бичлэг түүхэнд хадгалагдаж, сануулга шинэ хугацаагаар тоологдоно.
- Ажлаас гарсан ажилтны **Идэвхтэй** тэмдгийг арилгавал сануулга очихгүй, түүх нь хадгалагдана.

## Асуудал гарвал (SQL Editor дээр)
```sql
-- Resend-ийн хариу (алдаа байвал энд харагдана)
select status_code, content, created from net._http_response order by created desc limit 5;
-- Өдөр бүрийн ажил ажилласан эсэх
select status, return_message, start_time from cron.job_run_details order by start_time desc limit 5;
```
- `403` / "domain is not verified" → Resend дээр домэйн баталгаажаагүй байна (5-р алхам).
- "Resend API түлхүүр Vault-д алга" → 5.5-р алхмыг хийгээгүй.
- Апп "Өгөгдөл ачаалж чадсангүй" → 2-р алхам эсвэл CONFIG-ийн утгыг шалгана.
